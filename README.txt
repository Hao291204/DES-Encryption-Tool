DES ENCRYPTION AND DECRYPTION ASSIGNMENT
===========================================

Student: Gia Hao Tran
Language: Java

1. PROJECT DESCRIPTION
----------------------

This project implements the Data Encryption Standard (DES)
algorithm manually in Java.

The program asks the user for:

- Plaintext
- An 8-character secret key

It then:

1. Encrypts the plaintext.
2. Displays the ciphertext in hexadecimal.
3. Decrypts the ciphertext.
4. Displays the recovered plaintext.
5. Verifies that the decrypted text matches the original text.

The Java Cipher API is NOT used to perform DES encryption or
decryption.

2. MODE OF OPERATION
--------------------

This implementation uses Electronic Codebook (ECB) mode.

DES works with 64-bit (8-byte) blocks. PKCS#5-style padding is
used when the plaintext is not an exact multiple of 8 bytes.

3. DES COMPONENTS IMPLEMENTED
-----------------------------

The implementation contains:

- Initial Permutation (IP)
- Final Permutation (FP)
- Permuted Choice 1 (PC-1)
- Permuted Choice 2 (PC-2)
- Expansion permutation (E)
- Eight DES S-boxes
- P permutation
- 16 Feistel rounds
- DES key schedule
- Left rotations
- XOR operations
- Encryption
- Decryption
- Padding and unpadding
- Hexadecimal ciphertext conversion

5. REQUIREMENTS
---------------

Java Development Kit (JDK) 8 or newer.

No external libraries are required.

6. COMPILATION
--------------

Open a terminal in the src folder and run:

javac Main.java DES.java

7. EXECUTION
------------

After compilation, run:

java Main

Example:

Enter plaintext: Hello DES
Enter secret key (8 characters): 12345678

The program will display the ciphertext and then decrypt it.

9. DECRYPTION
-------------

For decryption, the same DES process is used, but the sixteen
round keys are applied in reverse order.

10. KEY
-------

The program accepts exactly 8 ASCII characters as the secret key.

DES receives a 64-bit key input. Eight bits are traditionally
used for parity, leaving an effective key length of 56 bits.

11. EDUCATIONAL NOTE
--------------------

This program is intended for educational purposes.

DES is obsolete for modern security because its effective key
size is only 56 bits. Modern applications should use AES or
another modern authenticated encryption algorithm.

12. IMPORTANT IMPLEMENTATION NOTE
---------------------------------

The assignment asks for an implementation of DES. Therefore,
this project does not use Java's built-in DES Cipher class to
perform the encryption or decryption.
